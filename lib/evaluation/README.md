# AcademicAI Evaluation Harness (Milestone 10)

> **Milestone Notice**: Evaluation harness will be constructed in Milestone 10.
> Test datasets with real university announcements and academic circulars will be benchmarked.

### Evaluation Metrics Targets:
- Document Classification: Accuracy, Precision, Recall, Macro-F1
- NER: Strict & Relaxed Entity Precision, Recall, F1
- Temporal Extraction: Exact Match & Timestamp Resolution Accuracy
- Duplicate Detection: Precision, Recall, F1
- Change Detection: Reschedule/Cancellation Accuracy
- Chatbot Tool Execution: Grounded Response Rate & Tool Selection Precision
